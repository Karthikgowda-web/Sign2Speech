# Kannada Language Voice Support

## Overview
The Sign2Speech application now supports Kannada (ಕನ್ನಡ) language for text-to-speech conversion.

## How to Use Kannada Voices

### 1. Voice Selection
- Open the voice dropdown in the Home page
- Look for the "🇮🇳 Kannada (ಕನ್ನಡ)" section
- Select any Kannada voice from the list
- The first Kannada voice is automatically selected if available

### 2. Speaking Text
- After selecting a Kannada voice, click "🔊 Speak Text"
- The text will be spoken in Kannada pronunciation
- The status will show "Speaking in Kannada (ಕನ್ನಡ)..."

## Browser Support

### Chrome/Edge (Recommended)
- Full Kannada TTS support
- Multiple Kannada voices available
- Best pronunciation quality

### Firefox
- Limited Kannada voice support
- May need to install additional language packs

### Safari
- Basic Kannada support
- May require system language settings

## Installing Kannada Voices

### Windows
1. Go to Settings > Time & Language > Language
2. Add Kannada language pack
3. Install speech pack if available
4. Restart browser

### macOS
1. System Preferences > Keyboard > Input Sources
2. Add Kannada
3. System may download voices automatically

### Linux
```bash
# Install Kannada TTS (eSpeak or Festival)
sudo apt-get install espeak espeak-data
```

## Troubleshooting

### No Kannada Voices Available
1. **Check browser**: Chrome/Edge have best support
2. **Install language pack**: Add Kannada to system languages
3. **Restart browser**: Voices load on browser start
4. **Check console**: Look for voice loading messages

### Voice Not Working
1. Ensure voice is selected from dropdown
2. Check that text is not empty
3. Try different Kannada voice
4. Check browser console for errors

1. Convert sign language to text: "HELLO" → "ನಮಸ್ಕಾರ"
2. Select Kannada voice from dropdown
3. Click "Speak Text"
4. Hear pronunciation in Kannada

## Notes
- Kannada voices are prioritized in the dropdown
- If no Kannada voices are found, English voices are available
- The system automatically detects and uses the correct language
- Custom text can be typed and spoken in Kannada
