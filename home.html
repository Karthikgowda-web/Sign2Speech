📚 Quick Start Guide

Option A: Import Excel File (For large datasets)

  1. Click "Import Excel File" button
  2. Select your Excel file (.xlsx or .xls)
  3. Wait for import to complete
  4. Click "Train Model" button

Option B: Collect Data Manually

  1. Enter Sign Label: Type a letter (A-Z) or word (e.g., "A", "HELLO")
  2. Set Samples: 30-50 samples is good to start (more = better accuracy)
  3. Start Camera: Click "Start Camera" button
  4. Collect Data: Click "Start Collecting Data" and perform the sign repeatedly
  5. Repeat: Do this for at least 2 different signs
  6. Train: Click "Train Model" button (takes 2-5 minutes)

📖 See EXCEL_IMPORT_GUIDE.md for Excel format requirements
